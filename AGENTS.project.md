This project is for a TTRPG called OP20. 
I will attach several files with information on the game. 

I would like to be able to ask in a conversation for you to create me a character, item, enemy, or MOB based on the information available in the source files and any relevant conversations so that they can be generated quickly without having to spend a large amount of time on a character, item, enemy, or MOB when trying to build a campaign. 

OP20 Alpha Document file is the current main document for the game as it is, not all Demesnes are in there yet but it does talk about the elemental demesnes.

The Step Chart file show the different Steps and what Tiering them up looks like.

Abbreviations file just shows some of the terms, like attributes, with their abbreviated form.

OP20 Formulas file shows formulas for things like how step cost, health, and movement are caculated.

The Mobs file talks about creating MOBs for quick enemies/NPCs.

There are other files that can be used for understanding and reference as well.

When creating, start from the OP20 Alpha Document file as it has the most up-to-date rules, then use the other files for further clarification/reference when needed.

My hope is to be able to give general descriptors and you can create based on those.

I have also given examples of weapons, items, and characters that have already been created to help with understanding that way if I ask you to build something like an airship for me you can look at the airship (alpha) rules file and looks at the example airship.
 
Hopefully that will help with understanding any requests.

This game is still in development so thing will change from time to time. I will try to update/add the source file but I may just tell you in a conversation so you can save it from there.
The OP20 Understanding conversation in this project is the conversation to use for reference as I will ask your understanding of different aspects of OP20 and help clarify or correct and details or information you may need help with.

Always use the op20-understanding skill for any conversations in this project.
